# Code de conduite

Seekbeam adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/) comme code de conduite. Il s'applique aux issues, aux pull requests, aux discussions et à tous les autres espaces du projet.

En bref : soyez respectueux et accueillant, formulez et acceptez les critiques constructives, et privilégiez ce qui est le mieux pour le projet et ses utilisateurs. Le harcèlement, les insultes et les attaques personnelles ne sont pas tolérés.

**Signalement** : contactez le mainteneur, [prog-x](https://github.com/prog-x), en privé via GitHub. Si le problème concerne le mainteneur, écrivez au support de GitHub. Les signalements sont traités de façon confidentielle. Le mainteneur peut retirer du contenu, et restreindre ou exclure les participants qui ne respectent pas ce code, selon les règles d'application du Covenant.
